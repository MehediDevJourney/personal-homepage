# Advanced Personal Home Page

This is a responsive, fast-loading personal homepage designed for Chrome and GitHub Pages.

## Features
- Multiple responsive tiles: Social, Chat, Work, Utilities
- Fully responsive search bar
- Direct link open functionality
- Fast loading and lightweight UI
- Dark mode ready

## Setup on GitHub
1. Create a public repository named `personal-homepage`
2. Upload `index.html`, `style.css`, `script.js`, `assets/` folder, `README.md`
3. Enable GitHub Pages: Settings → Pages → Branch: main → Root → Save
4. Access your page: `https://<username>.github.io/personal-homepage/`
5. Set Chrome homepage: Settings → Home page → URL

## Customization
- Add/remove tiles in `index.html`
- Replace icons in `assets/`
- Modify `style.css` for theme changes
- Update `script.js` for additional functionalities
